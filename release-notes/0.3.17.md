# 0.3.17

This release repairs automatic game updates after Funcom moved database dumps into the server PVC.

## Reinstall step

After updating the desktop app, open each server's Management Service card and click Install / Update. The fix runs in the on-host service and requires the new `dune-server-service` binary.

## Fixed

- Automatic updates now verify pre-update backups in `Saved/DatabaseDumps` on the server PVC. The service also retains the former `/funcom/artifacts/database-dumps` location as a compatibility fallback for older server packages.
- A pending update now uses a stable backup name and reuses an existing non-empty dump. If a later update step fails and retries, the service no longer creates a fresh database dump every 15 minutes.
- Backup task logs now report the path that was actually verified instead of always reporting the former artifacts path.
- A nonzero vendor update exit is accepted only when Steam and the live BattleGroup prove the requested build was applied. This handles the vendor script's final non-idempotent symlink refresh without hiding a real update failure.

## Notes

- Existing update schedules and pending updates are preserved.
- The fix supports both local-path and hostPath Kubernetes persistent volumes.
